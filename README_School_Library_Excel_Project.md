# School & Library Book Inventory — Advanced Excel Mini Project

## Project overview
This mini assignment uses a synthetic dataset to analyse book inventory across several schools and libraries. It is designed for an Advanced Excel portfolio project and GitHub repository.

## Business problem
The school group needs to understand stock on hand, inventory value, book issue rates, and which book records need replenishment.

## Files
- `School_Library_Books_Advanced_Excel_Mini_Project.xlsx` — raw data, lookup lists, formula-based summaries, and dashboard.
- `Advanced_Excel_Mini_Assignment_Brief.pdf` — assignment brief and deliverables.

## Excel skills demonstrated
- Excel Tables, filters, freeze panes, and structured data
- `IF`, `IFERROR`, `XLOOKUP`, `COUNTIF`, `COUNTIFS`, `SUMIF`, `SUMIFS`, `AVERAGEIF` / `AVERAGEIFS`
- Inventory calculations and percentage formatting
- Conditional formatting for low stock and reorder status
- KPI cards and charts
- PivotTables, PivotCharts, and slicers (complete as an extension task)

## Assignment tasks
1. Check for blank cells, duplicate Book IDs, and inconsistent categories.
2. Review formula columns: Stock, Stock Value, Reorder Level, Stock Status, and Issue Rate.
3. Create a PivotTable summarising Stock and Stock Value by Category.
4. Add School and Library slicers to the PivotTable/PivotChart.
5. Use `SUMIFS` and `COUNTIFS` to add a school-level analysis.
6. Improve the dashboard with slicers, clear titles, and a short insight section.
7. Write 3–5 findings based on the results after recalculating the workbook in Excel.

## Business questions
- Which book category has the greatest total inventory value?
- How many records are flagged for reorder?
- Which school has the highest stock value?
- Which categories have high issue rates?
- What would you recommend to reduce stock-outs without over-purchasing?

## Important notes
- All records are synthetic and created for learning; they do not represent a real school or library.
- The workbook includes formulas and a starter dashboard. PivotTables and slicers should be added in desktop Excel as part of the assignment.
- Open the workbook in Excel and allow formulas to recalculate before interpreting the dashboard.
